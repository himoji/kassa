# Phase 1 coordination (4 parallel agents, same working tree)

Tracks: A = core money path (apps/api), B = intelligence (apps/api), C = mobile (apps/mobile), D = mock-world + fixtures.

## Global rules
- Read docs/spec/TECH_SPEC.md, docs/spec/IMPLEMENTATION_PLAN.md, docs/DECISIONS.md (incl. the standards-first rule) before coding. Follow the spec exactly; when it is silent use the cited standard (ISO/IEEE/RFC/W3C) and note it in a code comment. New deviations → append a dated entry to docs/DECISIONS.md.
- Contracts live in packages/shared (@kassa/shared). You may ADD exports there; do not change existing exported shapes without appending a note to the "Contract changes" list below (other agents read it).
- Do NOT git commit. The coordinator commits after Phase 1.
- Only touch your owned paths (below) plus additive edits to packages/shared and docs/DECISIONS.md.
- Dependency installs: edit your own package.json, then `bun install` from repo root. If you hit a lockfile/install race, wait 30 s and retry.
- Money = integer minor units + ISO 4217 code. Time = Clock service (api) — never Date.now() directly in api modules.
- Verify library APIs against current docs (Fastify 5, Drizzle, @simplewebauthn v13+, AI SDK, Expo SDK 57), not memory.
