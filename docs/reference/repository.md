# Repository layout and licences

## Layout

| Path | Contents |
| --- | --- |
| `apps/api` | Fastify 5 API (TypeScript, Bun). Modules under `src/modules/` include `agent`, `ai`, `reader`, `rules`, `payments`, `rails`, `capture`, `budget`, `fx`, `screening`, `ledger`, `privacy`, `payees`, `mandates`, `users`, `auth`, `scheduler`, `demo`, `webhooks`, `wallet`, `credit-record`, `business` and `commerce`. Drizzle schema in `src/db/`, migrations in `drizzle/`, tests in `test/` |
| `apps/mock-world` | Fastify mock services: a Wise-shaped mock bank, a pizza shop, two food suppliers, a university, a landlord, an insurer, an email inbox, a "QR Wallet (simulated)", a POS emitter and a remittance sender |
| `apps/mobile` | Expo app (Expo Router, React Native Web, native passkeys), also built as KassaLite. Source in `src/app/`; the evidence room is `public/showcase/` |
| `packages/shared` | `@kassa/shared`: zod schemas, `CanonicalOrder`, `orderHash` and `mandateHash` (RFC 8785 JCS), reason codes, money helpers (integer minor units), IBAN helpers, mock webhook HMAC |
| `fixtures` | Seed data for Dana, 30 labelled invoice PDFs, sample statements, notification samples, a fictitious sanctions sample, FX example rates, recorded agent replays |
| `docs` | This site: guide, examples, architecture, security, reference, evidence (`docs/evidence/`, raw logs) and demo videos (`docs/demo/`) |
| `scripts` | `env-setup.ts`, `keys-generate.ts`, `dev-all.ts`, `deploy-vercel.sh`, `vercel-build.ts`, the demo-video recorder and more |
| `api/index.ts`, `vercel.json` | Vercel deployment (one function for the API and the mock world) |
| `docker-compose.yml`, `Caddyfile`, `apps/*/Dockerfile` | Optional Docker deployment |
