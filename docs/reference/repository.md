# Repository layout and licences

## Layout

| Path | Contents |
| --- | --- |
| `apps/api` | Fastify 5 API (TypeScript, Bun). `src/modules/`: `agent`, `ai`, `reader`, `rules`, `payments`, `rails`, `capture`, `budget`, `fx`, `screening`, `ledger`, `privacy`, `payees`, `mandates`, `users`, `auth`, `scheduler`, `demo`, `webhooks`, `wallet`, `credit-record`, `business`, `commerce`. Schema `src/db/`, migrations `drizzle/`, tests `test/` |
| `apps/mock-world` | Fastify mocks: Wise-shaped bank, pizza shop, two food suppliers, university, landlord, insurer, email inbox, "QR Wallet (simulated)", POS emitter, remittance sender |
| `apps/mobile` | Expo app (Expo Router, React Native Web, native passkeys), also built as KassaLite. Source `src/app/`; evidence room `public/showcase/` |
| `packages/shared` | `@kassa/shared`: zod schemas, `CanonicalOrder`, `orderHash` and `mandateHash` (RFC 8785 JCS), reason codes, money helpers (integer minor units), IBAN helpers, mock webhook HMAC |
| `fixtures` | Dana's seed data, 30 labelled invoice PDFs, sample statements, notification samples, fictitious sanctions sample, FX example rates, recorded agent replays |
| `docs` | This site; evidence and raw logs in `docs/evidence/`, demo videos in `docs/demo/` |
| `scripts` | `env-setup.ts`, `keys-generate.ts`, `dev-all.ts`, `deploy-vercel.sh`, `vercel-build.ts`, demo-video recorder, others |
| `api/index.ts`, `vercel.json` | Vercel (one function for API and mock world) |
| `docker-compose.yml`, `Caddyfile`, `apps/*/Dockerfile` | Optional Docker deployment |
